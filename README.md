A sports management simulator where you control a franchise and guide it through drafts, season simulations, and long-term organisational development. The system features AI-controlled teams, evolving prospects, dynamic career arcs, and continuous league progression. Each update expands depth and realism by improving core systems such as player generation, match simulation, and overall league behaviour.

The design is intended to function more as an ecosystem simulation than a traditional game. On startup, the user is prompted to optionally automate the initial draft process (a seven-round draft that repeats across seven cycles) and to load a custom roster profile. Any imported roster data is appended to existing team rosters rather than replacing them, allowing seamless integration into the current league state.

launcher and exe need to be in the same directory

Execution note: launch via Launcher.exe (not NHL be a GM v1.5.exe).
